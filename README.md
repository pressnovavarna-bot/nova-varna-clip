# Нова Варна — дневен вертикален клип

Прави клипа с **ffmpeg** върху безплатните машини на GitHub Actions.
Заменя json2video: няма кредити, няма лимит.

## Какво съдържа

| файл | за какво е |
|---|---|
| `render.py` | целият рендер: сваля снимките, прави гласа, субтитрите и видеото |
| `assets/logo.png` | логото, което влиза в клипа |
| `assets/logo_kragche.png` | кръглият вариант, ако решиш да го ползваш |
| `.github/workflows/render.yml` | описва как GitHub да пусне рендера и къде да качи готовото mp4 |

## Как работи

1. Make чете трите най-нови статии от рубрика „Акценти" и техните снимки.
2. Make чука на GitHub (`repository_dispatch`) и подава заглавията и снимките.
3. GitHub пуска машина, инсталира шрифта Roboto и `edge-tts`, и стартира `render.py`.
4. `render.py`:
   - сваля снимките, логото и двата банера от novavarna.net;
   - прави гласа с `bg-BG-BorislavNeural` (безплатно, през edge-tts);
   - сглобява субтитрите **от точните думи и тайминги**, които връща синтезаторът —
     затова `novavarna.net` винаги излиза правилно изписан;
   - рендира четирите сцени, слепва ги с кръстосано затихване и напечатва субтитрите.
5. Готовото mp4 се качва като *release* с етикет `clip-<дата>`.
6. Make сваля файла от този release и го качва в Google Drive.

## Настройка (веднъж)

1. Направи **публично** хранилище с име `nova-varna-clip`.
2. Качи в него `render.py` и папката `.github` (запази структурата).
3. Направи си токен: **Settings → Developer settings → Personal access tokens →
   Fine-grained tokens → Generate new token**
   - Repository access: само `nova-varna-clip`
   - Permissions → Repository permissions → **Contents: Read and write**
   - копирай токена, показва се само веднъж
4. В Make отвори сценария „Нова Варна → дневен клип (GitHub + ffmpeg)",
   модул **„Настройки (само тук се пипа)"** и попълни:
   - `repo` = `твоят-потребител/nova-varna-clip`
   - `token` = токенът от стъпка 3

## Тест без Make

В GitHub: **Actions → Рендер на дневния клип → Run workflow** и попълни трите
заглавия и трите линка към снимки на ръка. Ако там мине, проблемът е в Make.

## Какво може да се настройва

Всичко важно е най-горе в `render.py`:

| променлива | какво прави |
|---|---|
| `LEAD_IN`, `TAIL` | тишина преди и след гласа във всяка сцена |
| `XFADE` | дължина на прехода между сцените |
| `OUTRO_DURATION` | колко трае финалният кадър |
| `OUTRO_TEXT` | какво казва гласът накрая |
| `BANNER_*` | позиция и момент на влизане на банерите |
| `SUB_*` | цвят, размер и височина на субтитрите |
| `VOICE` | кой глас чете (`bg-BG-BorislavNeural` или `bg-BG-KalinaNeural`) |
| `VOICE_RATE` | темпо на говора; `-6%` е малко по-бавно от нормалното |
| `AUDIO_FILTER` | изчистване и изравняване на звука преди сглобяването |
| `PHOTO_MAX_H` | докъде може да се разпъне снимката на новината |

Логото е файл в хранилището (`assets/logo.png`) — сменя се със заместване
на файла. Банерите се теглят от novavarna.net, така че те се сменят направо в
сайта. И трите приемат както път до файл, така и адрес в интернет.
